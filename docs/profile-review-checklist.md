# Profile Review Checklist

Before updating the public profile README, verify:

| Check | Why |
| --- | --- |
| Flagship links resolve | Recruiters click fast |
| Archive repos are labeled honestly | Avoids overclaiming |
| Project names match GitHub repo names | Reduces confusion after renames |
| Claims have evidence links | Supports technical credibility |
| Old setup notes are not presented as current work | Keeps the profile focused |
