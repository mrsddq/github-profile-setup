# Portfolio Audit Checklist

Use this checklist before making a repo prominent.

## README

- clear problem statement
- tech stack
- setup commands
- demo command
- honest limitations
- result section

## Proof

- CI badge
- test command
- screenshots or outputs
- metrics CSV for ML repos
- deployed URL when appropriate

## Hygiene

- no committed secrets
- no `node_modules`
- no virtual environments
- no notebook checkpoints
- pinned dependencies
- useful `.gitignore`

## Research Repos

- reproducibility notes
- ablation plan
- architecture rationale
- dataset contract
- failure analysis section
